🚦 Rate Limiting (Leaky Bucket: limit_req_zone)

NGINX enforces a strict rate limit of 10 requests/second on the API. When a burst exceeds the leaky bucket capacity, NGINX immediately drops the traffic with HTTP 429 Too Many Requests before it reaches Node.js.

📐 Infrastructure Architecture Topology

All external traffic terminates strictly at NGINX on ports 80/443. All backend Express services remain isolated on a private Docker bridge network.
